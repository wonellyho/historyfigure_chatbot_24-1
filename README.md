# 역사인물 Talk
- 역사 속 인물들과 **대화(Talk)** 할 수 있는 메신저</br></br>
- 단순한 역사 공부가 아니라, **사용자가 직접 역사 인물과 대화하며 배운다**는 컨셉에서 출발
<hr>

### _역사 교육을 단순 암기에서 벗어나,_  
### _대화형 인터페이스로 흥미롭고 몰입감 있는 학습을 가능하게 하는 프로젝트_</br></br>

* 위의 이미지는 **앱 메인 화면,대화 시뮬레이션 UI / 플로우 차트** 입니다.  

> ### 목표
- **청소년과 일반 사용자들이 역사에 대한 흥미를 높이고, 학습 효과를 강화할 수 있도록 한다.**  
</br>

> ### 핵심 내용
- 역사 속 주요 인물(예: 세종대왕, 신사임당 등)과의 대화를 AI로 구현
- 정확한 인물정보를 크롤링한 정보를 기반으로 사실에 기반한 역사인물 설정  
- ChatGPT API를 활용한 자연어 기반 질의응답 시스템
- .env 파일에 API키를 담아서 사용합니다.
  

</br>

> ### 중요성 (기대효과)
- 기존 역사 교육 방식(교과서 암기 위주)의 한계 극복  
- **몰입형 인터페이스**를 통한 학습 흥미 유발  
- AI 기술을 활용한 **개인화된 역사 교육 서비스**로 확장 가능
